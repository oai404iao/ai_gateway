# ip-api.com 代理出口 IP 查询

> 类型：外部服务参考与诊断边界。
>
> 最近核对：2026-07-30。服务条款与限流应在部署前重新确认。
>
> 权威来源：[JSON API](https://ip-api.com/docs/api:json)、[使用条款](https://ip-api.com/docs/legal)。

## 检查代理出口

管理员在 Console 代理表单中测试当前草稿，对应 `POST /console/v1/network/proxies/test`。
它通过所填代理向固定 ip-api.com 端点查询出口，不修改代理、不派发 LLM 请求，也不参与计费。
精确请求/响应以[Console OpenAPI](../openapi/console-v1.yaml)为准。

| 结果 | 如何理解 |
| --- | --- |
| 成功返回 ip | 本次诊断链路观察到的出口 IP，不是长期保证 |
| 国家/ISP/proxy/hosting | 人工诊断信息，不能作为安全授权依据 |
| `429` 或倒计时 | 等待限流窗口，避免连续点击重试 |
| `502` / `504` | 诊断依赖或链路不可用，不等于全部上游不可用 |

## 外部接口关键语义

核对时免费 JSON 端点为 `http://ip-api.com/json/`。不指定查询 IP 时返回请求出口，
query 字段是该 IP，fields 可限制响应字段。免费接口只允许非商业用途且不提供 HTTPS；
商业使用或 HTTPS 需付费服务，网关不代部署者取得授权。

来源按出口 IP 限流，X-Rl 表示剩余请求，X-Ttl 表示距重置的秒数。
X-Rl 为零时调用方应等待。条款、额度和字段覆盖率属于外部服务边界。

## ai-gateway 兼容行为

- 支持 HTTP、HTTPS、SOCKS4/4a、SOCKS5/5h，复用数据面代理 URL/凭据校验规则。
- 测试刻意忽略草稿 enabled 和 no_proxy_hosts，确保 ip-api.com 不因绕过规则走本机出口。
- 使用独立有界客户端缓存，不挤占普通转发客户端。
- 编辑现有代理时，只有 scheme、host、有效 port 都不变，省略的用户名/密码才可复用；
  换端点必须重填隐藏凭据，防止把旧凭据发到另一个主机。
- 响应最多 64 KiB，连接/响应头/流空闲超时使用当前系统上游默认值。
- X-Rl 为零或 HTTP 429 后，同一诊断客户端在 X-Ttl 指示窗口内拒绝重复测试。

实现见 `src/application/proxy_test.rs`；外部失败只返回受限错误，不回显代理凭据或原始正文。

## 差异与限制

固定免费端点使用明文 HTTP，代理或链路参与者可修改结果，不能用它证明加密隧道安全。
测试不影响渠道健康、自动禁用、路由和费用，也不证明某个 LLM 主机可通过该代理访问。
要验证特定上游，应使用相应操作的确定性测试或经授权的真实调用，而不是扩大此诊断的含义。
