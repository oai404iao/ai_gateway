# DeepSeek 峰谷定价参考

> 类型：外部参考。
>
> 最近核对：2026-08-17。
>
> 权威来源：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 外部接口关键语义

DeepSeek 当前把 API Token 单价分为空闲时段与高峰时段：

- 空闲时段价格是高峰时段的一半；
- 高峰时段为 UTC `01:00–04:00` 与 `06:00–10:00`，其余时间为空闲时段；
- 相同的二倍关系同时适用于缓存命中输入、缓存未命中输入和输出价格。

第三方价格和时段可能变化，实际接入前仍须重新核对官方价格页。

## ai-gateway 兼容行为

`ai-gateway` 不把 DeepSeek 的时段硬编码为计费规则，也不自动抓取 DeepSeek 价格。模型
`advanced_billing.time_multipliers` 提供通用的每周 UTC 时段倍率；每个时段可选择开始星期，
旧配置省略星期时默认每天生效。Console 的模型定价子页提供
DeepSeek 预设，便于把基础价格作为空闲时段价格，并填入上述两个 `2` 倍高峰窗口。

时段按逻辑请求开始时间选择，采用开始包含、结束不包含的半开区间。跨午夜窗口可用开始时间晚于
结束时间表示；同一模型的窗口不能重叠。

## 差异与限制

- Gateway 当前只支持每周 UTC 循环，不支持 IANA 时区、夏令时或节假日日历规则。
- 一个窗口使用统一倍率，同时作用于输入、缓存输入、缓存写入和输出；不能为四类价格分别设置倍率。
- DeepSeek 预设默认选择周一至周日，只是表单辅助；应用后仍须由管理员核对基础价格、适用星期并
  显式保存。
- models.dev 价格同步不会创建、替换或清除管理员维护的时段倍率。

## 维护检查项

1. 核对 DeepSeek 官方高峰时段、倍率和适用计费项。
2. 若官方规则变化，更新 Console 预设、前端测试、本页核对日期和用户文档。
3. 保持外部 DeepSeek 行为与 Gateway 的通用计费保证分开描述。
