# 测试如何验证网关行为

> 状态：当前。

按故障能被观察到的位置选择测试。两个测试使用相同输入，不等于验证同一件事：Console 表单发出正确请求，不能代替服务端拒绝越权；SQLite 单写事务和 PostgreSQL 行锁需要分别验证。

| 要验证的行为 | 观察位置 |
| --- | --- |
| 请求准备、重试与透传 | 回环上游实际收到的方法、Header、body 和派发次数；SSE 比较事件，不假设 HTTP chunk 边界 |
| 费用与幂等 | 事先算出金额，用回执、余额和 Key 额度核验；重启、重复交付后再核对 |
| Console 契约与操作 | 用 OpenAPI 验证响应结构；用组件或浏览器操作真实控件，检查发出的请求及保存后可见的数据 |
| 插件与发行 | 加载实际动态库，检查命令结果与最终归档，而不是搜索源码字样 |

预期值来自公开契约、手算示例或独立观测。测试不泄露凭证时使用合成哨兵，拒绝路径同时核对错误和副作用。调整测试前，先确认剩余用例仍能在同一边界发现该回归。运行入口见[开发环境](getting-started.md)和[系统 E2E](system-e2e.md)。
