# 控制面软删除

> 状态：当前。资源删除使用不可恢复墓碑；历史财务、日志和审计引用继续有效。

删除让资源退出活动配置，不抹去已经发生的请求。普通列表、详情、可选项和运行时快照
过滤 deleted_at IS NULL；历史查询及结算仍按原 UUID 读取。
自然名称可复用，新对象获得新 UUID，不继承旧授权。

## 共同事务与保护

软删除没有回收站、恢复或物理清理 API。请求日志、审计、系统设置、会话和结算事实
不属于这些可删除资源；尤其不能把日志删除等同于删除费用。

删除使用详情 ETag/If-Match，并在同一控制面事务处理依赖、完整候选编译与审计，
提交后才发布 ArcSwap。PG 使用 SERIALIZABLE，SQLite 使用唯一写事务。
失败或取消不得留下部分解绑、审计或新快照。
旧快照在途请求可结束并结算，新请求不能认证已删除用户/Key。

数据库保护硬删除、墓碑恢复和非法重引用，不只依赖 Console。
秘密不进入删除影响或删除后审计；Secret 擦除不删除历史身份与费用归属。

## 身份与授权资源

### 用户

删除用户清除 email、密码和临时密码，撤销 Session/邀请，迁移到按角色选择的内置默认组。
所属普通 Key 同时墓碑化、设 revoked 并擦除明文 secret。
用户和 Key UUID 继续被日志、事实、回执与审计引用。
管理员不能删除自己或最后一个活动管理员。

### API Key

| 动作 | 后果 |
| --- | --- |
| 撤销 | 只设 status=revoked，记录仍在管理列表 |
| 删除 | 设 deleted_at/deleted_by、撤销、用唯一墓碑值覆盖 secret_value，从活动 API 隐藏 |

系统探测 Key 不能通过 Console 删除。
Key 名称可以重新使用，旧 secret 不能再认证；额度修改、撤销或删除不清零已用金额。

### 用户组

内置 user/admin 默认组受保护。删除自定义组同事务完成：

1. 普通成员迁移到内置用户组，管理员迁移到内置管理员组。
2. 关联可复用注册码禁用，但保留历史组引用。
3. 删除该组的 Codex quota 可见性关系。
4. 写组墓碑、审计并发布完整快照。

用户现有 Key 的固定路由授权不变；组迁移可能改变创建策略与 Fast 过滤，
确认文案须说明。部分唯一索引释放活动邮箱/自然名称，不复用 UUID。

## 上游拓扑删除语义

当前对象是管理组、逻辑渠道、能力、接入和凭证，不是旧渠道/组级联模型。

| 删除对象 | 事务内规则 |
| --- | --- |
| 能力 | 自动撤销全部引用候选，删除空 tier，停用无候选规则；推进受影响规则 ETag，审计记录结果 |
| 逻辑渠道 | 必须先删除其全部能力，存在未删除能力则拒绝 |
| 管理组 | 必须先清空未删除渠道，不能隐式级联删除整个图 |
| 接入 / 静态凭证 | 没有未删除渠道引用才可删除，disabled 或无路由仍算引用 |
| Codex 凭证 | 先解除全部渠道引用，再经专属生命周期清 Token 和墓碑；不走通用 CRUD |

能力自动清理适用于 Codex；其余候选的别名、权重、priority 和 strategy 不变。
能力墓碑、固定渠道授权来源和金融历史保留。
同名新 UUID 不继承授权；删除一个渠道不连带删除共享接入或凭证。
Codex 额度历史与 SQLite 未决维护 intent 不能通过删除或重启当作财务重置。

早期普通组/渠道的级联删除、影响预览 token 以及“能力被候选引用就拒绝删除”
均不是当前契约。依赖顺序见[上游拓扑](upstream-identity-capabilities.md)；
当前资源路径见[运维接口](../user/operations.md)。

## 计价模型

DELETE /console/v1/models/{id} 使用详情 ETag，串行事务：

1. 停用该模型 profile 下操作规则。
2. 撤销 tier/candidate，避免不可编辑墓碑永久占用能力。
3. 清空所有能力成对 test_model/test_pricing_model_id 引用。
4. 停用模型并写墓碑、审计，再发布候选快照。

profile、操作规则 UUID 和历史身份保留；日志 model_id/model_rule_id 仍有效。
模型目录、详情、models.dev 匹配、运行时价格和规则查询只读活动模型。
source_model_id 可用于新 UUID；手建或导入不能更新/复活旧墓碑。
数据库拒绝墓碑恢复、修改、硬删除和新路由/探测引用，两后端一致。

不删除能力的 available_models：它描述上游 wire model，不等于计价身份，
还可能被其他活动模型的候选使用。

## 历史与验证

日志和计量保存请求时客户端/上游模型、计价 UUID、规则 UUID、渠道与价格快照。
删除或同名重建不重算费用、不改变历史归属，不为展示历史重新暴露活动墓碑。
Console 危险操作使用不可恢复确认，显示各资源自动处理与保护条件。

验证任务：

- 墓碑从列表、详情、选项、更新及快照消失；当前 secret 失效，自然名称可重建。
- 用户/Key 关联删除、组按角色迁移、注册码禁用与系统身份/最后管理员保护。
- 删除前终态和在途请求仍能入账、重放，费用不因主体非 active 丢失。
- 删除能力正确修剪规则、推进 ETag；逻辑渠道/组按依赖退役。
- 固定授权来源保留但不授权墓碑或同名替代 UUID；共享接入/凭证引用检查覆盖停用配置。
- 模型规则 UUID 保留但停用，候选撤销、探测成对清空，墓碑不可重引用。
- 直接 SQL 绕过被拒绝，编译/审计失败全部回滚；组件/浏览器确认与 API 契约一致。

原实现按身份、上游资源、模型三阶段交付；阶段编号不是现行计划，
旧上游级联语义已经被新拓扑替代。其他资源的删除能力以各自 OpenAPI/实现为准，
不从本页推导未来功能。
