# Console 导航与页面交互规范

> 状态：当前。统一现有 Console 的导航语义、页面结构和术语；不改变后端授权、路由或数据模型。

## 页面层级与返回

- 顶层工作区由侧栏进入，不人为增加“返回首页”。
- 详情、新建和独立编辑页在标题上方只有一个父级返回链接。文字明确目标，
  如“返回渠道”“返回渠道接口能力”，不使用 `history.back()` 或 `navigate(-1)` 猜测来源。
- 从列表进入时，通过 `returnTo` 保留原列表的筛选、页码、页大小及工作区标签；
  新建后继续编辑的资源保留同一来源。编辑成功留在原页面，删除成功替换到来源列表。
  简单资源创建成功可返回列表；渠道等需要继续配置子资源的创建转到新对象详情；
  注册邀请码先显示一次性值，再进入详情。
- 直接打开详情或收到非法 `returnTo` 时，使用确定的资源父级。管理员返回目标只接受
  同源 `/admin/`，个人 Key 只接受 `/api-keys`；拒绝外站、协议相对地址、控制字符和反斜杠。
- 同页模型选择、操作选择及渠道标签使用 URL 状态。打开内嵌能力编辑器不覆盖原渠道的
  列表来源；此时唯一的页面返回指向能力列表，关闭编辑后才恢复返回渠道列表。
- 页面跳转使用真正的链接，支持键盘、复制地址和新标签页；样式复用 `buttonVariants`。
  保存、删除、测试、刷新、弹窗开关等状态操作使用按钮。需要先验证时间范围再打开统计的
  操作仍是按钮，不伪造可直接访问的失效链接。

实现入口：`src/lib/page-navigation.ts`、`NavigationLink`、`PageHeader`。
本节与下文的 `src/` 均相对于 `web/console/`。

## 列表

- 可打开详情的资源名称是链接；点击行的非交互区域仅是鼠标便利功能。
  复选框、密钥复制、行内按钮等独立操作不得触发行跳转，也不得嵌套在名称链接内。
- 请求日志和审计日志在当前列表打开详情抽屉，提供可聚焦的“查看详情”按钮；
  关闭抽屉回到原列表，不额外添加跨页返回入口。
- 普通资源列表采用 `ResourceTable` 的分页方式。可导航的列表把 `page` / `pageSize`
  保存在 URL；改变渠道组过滤或工作区标签时回到第一页，数据减少时校正越界页。
- 客户端模型保留主从工作区，不强制套用表格。移动端选择模型后显示编辑区，
  提供“返回客户端模型列表”的局部切换。
- 批量选择、分页、历史窗口切换和模型选择是不同的操作，不以“清理按钮”为由移除。
  Codex 凭证表保留账号状态与批量维护专用布局；敏感草稿不放入 URL 或浏览器存储。

## 详情与编辑布局

- 每个页面只有一个 `h1`。标签内列表使用二级标题，不重复完整页面标题、说明和导航条。
- 统一顺序为：父级链接 → 标题与必要关联动作 → 编辑内容 → 辅助信息 → 保存操作 →
  独立危险操作区。宽屏允许编辑区和辅助信息并排，窄屏优先显示编辑内容。
- 表单使用原生 `form` / submit，字段错误在对应字段展示。一个独立提交事务有一组保存动作，
  不在页头、侧栏和页尾重复放置同一个返回按钮。
- `AdminDetailShell` 同时服务管理资源和个人 Key；关联信息侧栏不再放置通用说明卡或第二个返回。
  多表单账户页、统计仪表盘和只读配额页保留业务分区，不强行改成单资源编辑器。
- 渠道接口能力列表和能力编辑器互斥显示，避免批量修改与打开的草稿竞争。
  渠道删除仅在“渠道设置”显示，能力编辑器只显示能力自身的删除操作。
- 长表格在自身容器横向滚动，页面本身不得横向溢出；长名称和 UUID 不能挤出主要操作。

## 草稿与保存

- 资源编辑页、系统设置、个人设置、个人资料和独立 Codex 导入页复用同一个草稿保护：
  页内返回、侧栏、标签切换和浏览器后退，在有未保存修改时先确认。
  刷新或关闭页面使用浏览器原生离开提醒。
- 保存中不能确认丢弃；失败保留草稿。保存或删除成功不额外弹出放弃草稿确认。
  确认放弃后，切回渠道设置不能恢复已经放弃的值。
- 系统设置切换分类需要确认丢弃，不能依赖分类组件重新挂载而静默清空。
- Codex 导入分别追踪尚未解析的输入和未成功导入的条目。全部成功后可以正常返回；
  部分失败或后来加载的新输入仍受保护。所有 Token 和草稿只保存在页面内存。
- 登录、注册、邀请激活和强制改密保持原有安全流程，不把任意来源 URL 当作认证后跳转目标。
  弹窗保留自身取消／关闭语义，不增加页面级历史返回。

## 标签与历史入口

统一用语：上游接入、上游凭证、渠道组、逻辑渠道、渠道接口能力、客户端模型、
操作路由规则、价格同步。凭证的认证类型与连接器类型分别显示，不把凭证管理重新挂回组。
价格中的 Token 单位统一使用十进制 `K` / `M` / `B` 简写（例如 `1M Token`）；
不足千保持原数值，编辑框和提交的计价数值仍保留完整精度。

| 历史入口 | 当前入口 |
| --- | --- |
| `/admin/model-setup` | `/admin/models` |
| `/admin/catalog` | `/admin/models?view=prices` |
| `/admin/routing/groups` | `/admin/routing/channels?view=groups` |
| `/admin/routing/logical-channels` | `/admin/routing/channels` |
| 旧 Codex 组管理入口 | `/admin/routing/upstream-credentials?connector=codex` |

重定向使用 replace 并保留有用的查询条件。删除旧模型接入总览和重复的横向配置导航条；
独立能力／操作规则索引继续作为兼容管理入口，不新增侧栏重复入口。

## 检查覆盖与验收

源码盘点覆盖全部路由页面及共享组件：

| 页面族 | 统一处理或保留理由 |
| --- | --- |
| 接入、凭证、渠道组、渠道、能力 | 来源返回、互斥嵌套编辑、标签层级、草稿保护 |
| 客户端模型、价格、操作规则、价格同步 | 工作区主从选择、关联链接、单标题及旧入口重定向 |
| 用户、用户组、策略、Key、注册码、代理、转换模板 | 统一列表链接、分页来源、详情布局、原生表单及草稿保护 |
| 拼车 | 统一列表、详情返回和编辑保护，保留席位及使用量分区 |
| 个人资料、个人设置、系统设置 | 保留业务表单分区，离开前确认修改 |
| 会话、本人配额、本人拼车、统计、状态、负载、排行榜 | 顶层页面无伪父级，保留历史／时间范围／刷新操作 |
| 请求日志、审计日志 | 表格键盘详情操作和原位抽屉，审计筛选补齐标签及翻译 |
| 登录、注册、激活、强制改密、404 | 链接与状态操作分离，保持认证守卫 |

自动化覆盖安全返回、旧入口、单标题、筛选／分页返回、键盘操作、直接访问、
浏览器后退、嵌套能力返回及草稿放弃。视觉检查至少覆盖桌面与 390px 窄屏，
并检查列表、普通详情、宽表格、模型工作区和中文标签。
